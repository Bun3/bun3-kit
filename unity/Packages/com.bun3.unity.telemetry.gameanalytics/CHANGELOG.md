# Changelog

## [0.1.0] - 2026-11-05

Requires Unity 6000.5 or newer; the assembly is skipped on older editors. Requires `com.gameanalytics.sdk` in the project manifest.

### Added

- `GameAnalyticsSink`, `GameAnalyticsSinkOptions`, `GameAnalyticsEvent`, `GameAnalyticsMap`, `IGameAnalyticsApi`, `GameAnalyticsSdkApi` and `TelemetryBuilder.AddGameAnalytics`.
