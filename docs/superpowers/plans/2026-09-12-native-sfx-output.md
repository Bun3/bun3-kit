# Native pooled SFX output

Approved implementation scope: optional output ownership in the audio core and a native path implementation in `audio.steamaudio`. The default output remains unchanged. No game policy or dry/direct compositor belongs here.

1. Add the generic `ISoundVoiceOutput` factory/lifecycle seam described in `../specs/2026-09-12-sound-voice-output.md`. Test handled DSP completion, unavailable failure, explicit stop/steal/fade/dispose, reentrancy and ordinary output preservation before implementation.
2. Extract the tested three-slot parameter algorithm into reusable lower-package storage. Producer leases capture an immutable generation; retire and reader quiescence precede reuse. Preserve the existing Dissonance API through forwarding. Test stale lease rejection and allocation-free reuse.
3. Add a cold PCM cache with an explicit managed-byte budget. Accept loaded mono/stereo Decompress On Load clips; reject unsupported streaming/unloaded clips with a diagnostic. Validate/copy a batch before committing it. Stereo positional input downmixes to a point source. Cache preparation is never hidden in playback.
4. Prewarm one native output per core source: renderer, fixed processing arrays, immutable clip PCM references, reusable mailbox, and a short looping stereo flatline clip. Generate dry PCM directly inside the same-source audio filter, render native stereo, and multiply into the incoming driver envelope so source/mixer gain is preserved once. UI/nonpositional requests return Unsupported and leave input untouched; unavailable handled requests remain stopped.
5. Apply logical pitch to the dry PCM cursor before HRTF processing, using linear interpolation with finite forward pitch clamped to 0..3. This preserves forward pitch/rate semantics; it does not reproduce Unity's proprietary resampler. Pitch zero freezes cursor/native state and emits silence. Loop boundaries interpolate into the first sample. Finite input completion drains native overlap/tails, then one further filter block before exposing completion to the pool.
6. Retire processing before source stop/reconfiguration. A held reader prevents reset/reuse and produces Unavailable. Native disposal remains on the main thread through a cold-created retirement host that survives source destruction until the reader releases. Device-rate/frame changes fail closed and require a cold replacement pool.
7. Run actual Unity source/listener gain tests, a short processed SoundSystem voice, pause/pitch/tail/reuse/UI/held-reader protocol tests, warm processing allocations, and the full existing core audio regression. Keep generated PCM/native/source-filter evidence distinct from hardware audibility.

The application owns range, probe coverage, room/permission policy and simulation revisions. SH already includes native path distance attenuation; additional path gain excludes bus volume and duplicated distance. `StartBlocked` defaults true until the current immutable producer lease receives a valid copied snapshot and explicit unblock.

## Validation outcome

The isolated Unity 6000.5.5f1 host passed `sound-production-play.xml` 185/185, including existing core behavior, the output-owner seam, four native SFX tests, two cache tests, five reusable-lease tests and voice playback/mailbox regression. Actual listener PCM verified source gain and mixer gain once; rendered periodic input verified pitch frequency and completion-rate changes. Controlled processing claims verified retirement, source destruction and reclamation without another source callback. A deterministic delayed-reader mailbox failure was reproduced before the admission fix. The dedicated default-renderer factory test passed in the six-test native acoustic asset/factory EditMode run. No C# warnings or errors appeared in the final PlayMode log. Metadata and XML documentation were finalized after this executable-code validation.
